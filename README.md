# krs_kampus

Aplikasi KRS mini berbasis Flutter.

## Langkah menampilkan aplikasi

1. Buka folder project di VS Code.
2. Buka terminal dengan shortcut Ctrl + `.
3. Jalankan perintah berikut:

```bash
flutter pub get
flutter run -d chrome
```

4. Jika sudah terhubung dengan emulator atau perangkat, Anda juga bisa menjalankan:

```bash
flutter run
```

5. Aplikasi akan muncul di browser Chrome atau emulator yang aktif.

## Catatan
- Pastikan Flutter SDK sudah terinstal dan sudah masuk PATH.
- Jika muncul pilihan device, pilih Chrome atau emulator yang tersedia.
- Jika ingin menjalankan langsung dari VS Code, bisa tekan F5 dan pilih device.
